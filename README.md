# The Guardian views for Localnet

How a list of results and a page look in Localnet, a browser extension that is a personal search engine, after the
Guardian: a navy masthead over a grid of tiles, each under a thin red rule with a red kicker before its serif headline,
the first story the lead; and in Read, a red kicker over a large serif headline, the byline in red, the text in a serif.
Listed by the view source Localnet starts with, [localnet-views](https://github.com/opowell/localnet-views), whose README
says how a view is written.

- `source.json`: the views, and their files.
- `listing.html`, `listing.css`: the listing view, offered in Show as.
- `content.html`, `content.css`: the content view, Read's Look: its head over the page, and the page restyled.
